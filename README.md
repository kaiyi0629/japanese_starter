# まいにち日語｜每天一點日文

零基礎日文互動學習網站，作為 Vibe Coding 作業。網站程式全部位於 `index.html`，直接開啟即可使用。

## 檔案

- `index.html`：網站，包含 HTML、CSS、JavaScript 及題庫。
- `規格書.md`：專案想法、功能、互動規則、技術限制與驗收標準。
- `README.md`：操作、公開網站及作業繳交流程。

## 如何使用

1. 雙擊 `index.html`，用瀏覽器開啟。
2. 五十音：切換平假名／片假名，點選字查看讀音、試聽或標記熟悉。
3. 生活單字：切換分類，點卡片看中文，點發音按鈕試聽。
4. 小測驗：選模式並開始。全部題庫模式十題，單一主題六題；答完可查看成績並只練錯題。
5. 若裝置沒有日語語音，會顯示提示。發音按鈕的聲音取決於裝置與瀏覽器，建議先在繳交時使用的裝置確認。
6. 完成次數、最高分及熟悉標記會儲存在目前瀏覽器。最高分只計一般完整十題測驗；本機檔案與 GitHub Pages 的紀錄分開。

## 上架後手動檢查

- 在電腦與手機開啟網址，確認畫面與功能導覽可操作。
- 點選五十音，切換片假名，標記熟悉並重新整理，確認標記保留。
- 測試單字的分類、翻卡與語音。
- 完成一次十題測驗，刻意答錯一題，檢查分數與「只練錯題」。
- 練習單一主題，確認為六題且不更新十題最高分。
- 使用 Tab、Enter 操作按鈕及選單。
- 需要展示時先清除紀錄，再重新做一遍學習流程。



## 限制

第一版包含 46 個基本清音、24 個單字，沒有登入、跨裝置同步或內建 AI 回答。題庫及回饋由固定資料和 JavaScript 提供。日語語音可用性取決於使用者裝置。
